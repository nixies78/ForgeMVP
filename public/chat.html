This page was opened straight from disk (file://) - nothing here can work
Your address bar starts with file://. Browsers block the page scripts that way, which is why Send does nothing. Fix it in three steps:
  1. Open C:\VibeCoding\ForgeMVP in File Explorer.
  2. Double-click start.bat (or run npm start in this folder).
  3. Open http://localhost:5173/chat.html.
The page scripts did not load
Buttons on this page will do nothing until they do. Hard-refresh with Ctrl+Shift+R, check the browser console for the error, and make sure the site is being served by npm start rather than opened from a file path.
