Create Your Project

Open UEFN (via the Epic Games Launcher, or "Launch UEFN" from Fortnite's Creative options) and start a new project.

  1. Click New Project in the UEFN Project Browser.
  2. Choose the KPop Demon Hunters brand template from the template picker so your project starts with its themed assets already loaded.
  3. Give your project a name that matches your game idea.
  4. Open the project — it loads into the UEFN editor with your starter island/assets ready to go.

Save before you change anything else: the template's own maps are never overwritten, so a fresh save is your way back if an experiment goes wrong.
