  1. Open C:\VibeCoding\ForgeMVP in File Explorer.
  2. Double-click install-startup.bat - the server then starts with Windows, and a ForgeMVP Admin shortcut appears on your desktop.
  3. From then on, use that shortcut or http://localhost:8080/.

Do I need to know Unreal Engine?

Start with an idea in everyday language. Forge extends your Unreal workflow with a design file that makes the next steps clear.

Does Forge build the game for me?

No. It creates the design blueprint, not a finished game. You stay in control of what gets built and how.

What’s in the design file?

The game concept, core loop, player systems, world, progression, and a focused plan for your first playable.
