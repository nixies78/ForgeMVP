# Home screen design-mode art

Line-art panels for the three "how do you want to design your game?" cards, in the
app's own visual language: **white outlines on the library canvas, colour only as
accent** — every accent is a token read out of `support/library.html`.

Generated by `support/make_design_mode_icons.py`; do not hand-edit the images.
Re-run the script after changing a colour or a shape.

## Files

| Panel | Image | Transparent |
|---|---|---|
| Answer Questions | `guided.jpg` | `guided-transparent.png` |
| Randomise | `randomise.jpg` | `randomise-transparent.png` |
| Chat with AI | `ai_chat.jpg` | `ai_chat-transparent.png` |
| Randomise (alternate) | `slots.jpg` | `slots-transparent.png` |

`slots` is an **alternate for the randomise card**, not a fourth card. The panel
set is three (see `DESIGN_MODES` in `public/js/guide/content.js`); swap a panel's
`image` to `images/design_modes/slots.jpg` to use the slot machine instead of the
wheel, or add a fourth panel if the flow grows one.

## Spec

| Spec | Value |
|---|---|
| Size | **900 × 600 px** (3:2) |
| Format | JPG (transparent PNG also supplied) |
| Displayed at | ~257 × 171 px in a 3-column row; full card width on mobile |
| Scaling | `object-fit: cover` — the outer ~3% can crop on a narrow window |

The wheel and the slot machine are drawn at 94–95% scale for exactly that reason,
so the pointer and the base stay inside the crop.

## What each panel is

| Panel | Subject | Accent tokens |
|---|---|---|
| `guided` | One root, three steps, one goal — a small process tree, not a fork diagram | `#33BFFF` root and one highlighted branch, `#5FE367` goal |
| `randomise` | Wheel of fortune: bright wedges, white rim and pointer | `#33BFFF` `#F9A91F` `#44D5BF` `#F7D82B` `#868AFD` `#FE8539` |
| `slots` | Slot machine with three reels, amber lever, star / diamond / cherry | `#F9A91F` lever, `#F7D82B` `#F9A91F` `#FE8539` symbols |
| `ai_chat` | Two speech bubbles — one with `…`, one with the AI sparkle | `#868AFD` sparkle, `#33BFFF` front bubble |

`#F9A91F` is the amber the app already uses for spin / locked, so the wheel and
the slots panel carry the same "randomise" signal.

## Notes

* No text is drawn into any image. The cards supply their own headings, so the
  artwork survives translation and never fights the copy.
* The transparent versions keep the same framing, with the glow dialled back (a
  glow tuned against the dark canvas is too heavy once the canvas is gone) and a
  faint dark outline hugging the silhouette, so the art still holds its shape on
  a light surface.
* QA sheets land in `support/`: `design-mode-icons-check.png` (the set),
  `design-mode-icons-cardsize.png` (at real card size) and
  `design-mode-icons-check-transparent.png` (the cut-outs).
